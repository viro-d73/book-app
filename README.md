# Pagewise

A dark-mode book and fan-fiction tracker for iPhone (runs in Safari, installs to the home screen).

Features: 1–10 ratings (0.5 steps), tags and filters, Bought / To-buy TBR lists, TL;DR notes, collections,
online book search and covers (Open Library / Google Books), fan fiction with words-to-pages conversion,
on-going vs completed, and a progress report with genre breakdown and books vs fic.

## Host it with GitHub Pages
1. Create a new GitHub repository and upload everything in this folder.
2. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
3. After a minute your app is live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.
4. Open that address in Safari on your iPhone, tap Share, then "Add to Home Screen".

Data is stored in the browser on your phone. Use Settings > Copy backup to keep a copy.
